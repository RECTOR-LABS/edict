# Edict

> Multi-tenant client docs delivery platform. Issued by RECTOR.

**Status:** Bootstrapping — awaiting kickoff brainstorm.

---

## Concept

A rector issues edicts. Edict is a platform for delivering formal, authoritative documents to clients — branded dashboards, per-client isolation, magic-link access.

Purpose: replace ad-hoc file sharing with a proper product for RECTOR LABS client engagements.

## Brand

**Edict** — from Latin *edictum*, a formal proclamation issued by a ruler. Tied directly to RECTOR (Latin *rector*, "ruler/governor").

- **GitHub:** `RECTOR-LABS/edict`
- **Target domain:** `edict.rectorspace.com`
